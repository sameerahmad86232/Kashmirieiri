# Kashmiri Keyboard

Native Android system-wide Kashmiri Perso-Arabic keyboard.

## Build

Open this folder in Android Studio and run **Build → Build APK(s)**. Install the APK, then enable **Kashmiri Keyboard** under Android Settings → System → Keyboard → On-screen keyboard.

The first version includes Kashmiri letters, extended letters, combining marks, punctuation, delete, space, and enter. Transliteration, suggestions, themes, and dictionary integration are planned next.
